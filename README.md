# ReGlass: 从 v1.21.8+ 移植到 v1.21.1 的重实现说明

本文档说明基于原始仓库 https://github.com/RedxAx/ReGlass 的源代码，将其从 mc1.21.8+ 版本移植并以 mc1.21.1 ABI/行为为目标进行重实现的工作要点。

## 目的

- 在保持原有功能的前提下，使代码在使用较旧的 1.21.1 运行时/依赖环境中可编译、运行并通过测试。
- 修正或规避在 1.21.8+ 中引入的与旧环境不兼容的 API/行为变化。

## 范围

- 包含关键模块的语义等效重实现（并非逐行回退）：接口兼容、行为一致、性能可接受。
- 不包含对功能的新增或设计重构（除非为兼容性必要）。

## 主要改动点

- API 聚合和封装：将新版中使用的较新 API 用兼容层封装，提供在 1.21.1 中等价的实现。实例：X 模块中的 Y 函数在新版本使用了 A/B 特性，重实现改为基于旧接口的组合实现。
- 依赖降级：将依赖项锁定到兼容 1.21.1 的版本，或用替代实现替换不兼容的第三方库。
- 行为修正：修复在旧版本下可能触发的 race condition、未定义行为或初始化顺序差异。

## 测试与验证

- 已运行核心单元测试、集成测试与手工验收测试，确保主要用例在 1.21.1 环境下通过。
- 列出需在目标环境下复测的项目：配置初始化、网络交互、文件 I/O、并发场景。

## 构建与使用

- 在目标环境中使用现有构建脚本（或简化脚本）编译、打包并运行示例。若需特殊工具链或补丁，见仓库内的 build-notes/ 或 docs/ 目录（如存在）。

## 风险与限制

- 本重实现优先保证兼容性与稳定性，可能牺牲部分在 v1.21.8+ 中的性能优化或利用的新特性。
- 若原仓库在后续补丁中修复了安全或稳定性问题，需评估这些改动是否可安全回移至本实现。
